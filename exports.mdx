Motive exports 114 animated icon components, the universal `IconShell` wrapper, and the `useIconTrigger` animation state hook directly from the package barrel.

## Installation

```bash
npm install rex-motive framer-motion
# or
yarn add rex-motive framer-motion
```

## Quick Import

```ts
import {
  AnimatedBell,
  AnimatedRocket,
  AnimatedBrain,
  AnimatedFolder,
  AnimatedCloudUpload,
  AnimatedScissors,
  AnimatedQRCode,
  AnimatedWallet,
  AnimatedChartLine,
} from "rex-motive";
```

Every icon accepts the same [shared props](/props-reference): `size`, `strokeWidth`, `color`, `trigger`, `loop`, `active`, `ariaLabel`, and `className`.
