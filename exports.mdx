Motive exports over 115 premium animated icon components, universal shell wrapper, and animation state hooks directly from the package barrel.

## Installation

```bash
npm install rex-motive framer-motion
# or
yarn add rex-motive framer-motion
```

## Quick Import

```ts
import {
  AnimatedBell,
  AnimatedRocket,
  AnimatedBrain,
  AnimatedFolder,
  AnimatedCloudUpload,
  AnimatedScissors,
  AnimatedQRCode,
  AnimatedWallet,
  AnimatedChartLine,
} from "rex-motive";
```
