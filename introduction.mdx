## Welcome to Motive

**Motive** (`rex-motive`) is a production-quality, open-source library of hand-crafted animated icons for React, powered by [Framer Motion](https://www.framer.com/motion/).

Instead of applying uniform scale or rotation effects across every icon, Motive features **meaningful micro-interactions** tailored to each icon's real-world semantics:
* 🔔 **Bells swing and ring** smoothly on notification alerts.
* 🗑️ **Trash cans flip open** their lids on action.
* 🏹 **Arrows travel and bounce** along vector vectors.
* 🔒 **Locks latch and unlatch** smoothly.

<Check>
**Production Verified**: Every animation rendered in these docs and on the live site is driven by the exact same `rex-motive` React component package consumers ship.
</Check>
